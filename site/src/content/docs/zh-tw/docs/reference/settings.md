從最左邊活動列的 **設定** 開啟。左邊列出各個分類，右邊一次顯示一個分類；打開時會停在上次使用的分類。

**改了就生效。** 沒有「儲存」按鈕：

- 清單、開關、選項，一選就套用。
- 需要輸入的值（字型大小、行高、回看範圍、位址、端點），按 **Enter** 或離開欄位時套用。在欄位裡按 **Esc** 會放回已儲存的值。
- 若變更無法儲存，欄位下方會出現訊息，欄位也會顯示回已儲存的值。

有兩個值只認它自己的按鈕或 **Enter**，離開欄位不會套用：Slack token（避免貼到一半的 token 被存下來），以及遠端存取的 port（變更它會中斷已連線的裝置）。

「終端」與「Agent 與 session」兩個分類的最下方有 **回復預設**。它會先確認，再把該分類回復成預設值，不會改動其他分類，也不會改動語言。

## 一般

介面語言（英文或繁體中文）。spekterm 寫給 agent 讀的文字維持英文。

## 終端

- **字型** —— 系統上安裝的任何等寬字型；留空就是系統預設。在 macOS 上，清單只提供系統預設的等寬字型。
- **字型大小** 與 **行高** —— 留空就是預設值。
- **預覽** —— 用選定的字型顯示一段範例，包含容易混淆的字元。預覽會隨著輸入即時更新，不必等到套用。
- **GPU 加速** —— 用 GPU 繪製終端機。如果終端機在你的電腦上顯示不正常，就把它關掉。

## Agent 與 session

- **在狀態列顯示 agent 狀態** —— 請 `claude` 把它的模型、context 用量與花費回報給 spekterm，顯示在狀態列上。你自己的 Claude Code status line 照常運作。這項設定只對變更之後建立的 session 生效。
- **讓閒置的 session 休眠** —— session 閒置超過選定的時間，就結束它的行程，但 session 仍留在 workspace 裡，之後可以喚醒。可選關閉、4 小時、24 小時（預設）、3 天或 7 天。畫面上正在顯示的 session、正在工作的 agent，以及正在跑工作的 shell，都不會休眠。在 macOS 上，閒置的 shell 永遠不會自動休眠。見[終端機與 session](/zh-tw/docs/using/terminals-and-sessions/)。
- **Agent session 顯示** —— 所有 agent session 要顯示終端機還是對話檢視。這和 agent session 分頁旁的切換鈕是同一個設定。見[對話檢視](/zh-tw/docs/using/conversation-view/)。

## 整合

Slack 連線：token、回看範圍與 API 端點。見[收件匣與 Slack](/zh-tw/docs/using/inbox-and-slack/)。決定提及開在哪裡的路由規則，仍然放在收件匣裡。

## 遠端存取

遠端存取的狀態（關閉；開啟，以及配對了幾台、連線中幾台；或沒有運作的原因）、開關、port、配對，以及已配對的裝置。若遠端存取無法啟動，左邊的分類清單會標示這個分類。見[遠端存取](/zh-tw/docs/using/remote-access/)。

## 關於

你正在執行的建置的版本、建置時間與 commit，回報問題時用得到。
