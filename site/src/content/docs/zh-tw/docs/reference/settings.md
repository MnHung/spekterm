從最左邊活動列的 **設定** 開啟。左邊列出各個分類，右邊一次顯示一個分類；打開時會停在上次看的分類。

**改了就生效。** 沒有「儲存」按鈕：

- 清單、開關、選項，一選就套用。
- 要打字的欄位（字型大小、行高、回看範圍、位址、端點），按 **Enter** 或離開欄位時套用。在欄位裡按
  **Esc** 會放回已存的值。
- 若變更無法儲存，欄位下方會出現訊息，欄位也會顯示回已存的值。

有兩個值只認它自己的按鈕或 **Enter**，離開欄位不會套用：Slack token（避免貼到一半的 token 被存下來），
以及遠端存取的 port（變更它會中斷已連線的裝置）。

「終端」與「Agent 與 session」兩個分類的最下方有 **回復預設**，會先確認，再把該分類還原。它不會改動其他
分類，也不會改動語言。

## 一般

介面語言（英文或繁體中文）。spekterm 寫給 agent 讀的文字維持英文。

## 終端

- **字型** —— 系統上安裝的任何等寬字型；留空即系統預設。在 macOS 上，清單只提供系統預設的等寬字型。
- **字型大小** 與 **行高** —— 留空即預設值。
- **預覽** —— 以選定的字型顯示一段範例，包含容易混淆的字元。你打字時它就會跟著變，不必等到套用。
- **GPU 加速** —— 以 GPU 繪製終端。若終端在你的機器上顯示不正確，把它關掉。

## Agent 與 session

- **在狀態列顯示 agent 狀態** —— 請 `claude` 把它的模型、context 用量與花費回報給 spekterm，顯示在狀態列。
  你自己的 Claude Code status line 照常運作。只對此後建立的 session 生效。
- **讓閒置的 session 休眠** —— 閒置超過選定時間的 session 會結束它的行程（可選關閉、4 小時、24 小時（預設）、
  3 天或 7 天），但仍留在 workspace 裡，之後可以喚醒。畫面上正在顯示的 session、正在工作的 agent、正在跑工作的
  shell 都不會被休眠。在 macOS 上，閒置的 shell 永遠不會被自動休眠。見 [終端與 session](/zh-tw/docs/using/terminals-and-sessions/)。
- **Agent session 顯示** —— 所有 agent session 都顯示終端或對話 view。與 agent session 分頁旁的切換鈕是同一個
  設定。見 [對話 view](/zh-tw/docs/using/conversation-view/)。

## 整合

Slack 連線：token、回看範圍與 API 端點。見 [收件匣與 Slack](/zh-tw/docs/using/inbox-and-slack/)。決定一則提及
開在哪裡的路由規則仍留在收件匣。

## 遠端存取

遠端存取的狀態（關閉；開啟，以及配對了幾台、連線中幾台；或沒有在運作的原因）、開關、port、配對，以及已配對的
裝置。若遠端存取無法啟動，左邊清單會在這個分類旁標示。見 [遠端存取](/zh-tw/docs/using/remote-access/)。

## 關於
