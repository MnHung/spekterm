spekterm 是一個桌面工作台，讓你在各個 repository 裡跑 Claude Code session，並在側欄顯示每個 session 正在做的
OpenSpec change。目前提供 Linux（x86_64）與 Apple Silicon 的 macOS 版本；Windows 與 Intel Mac 尚未支援。
