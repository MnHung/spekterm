每個 `claude` session 都有兩種呈現方式：**終端**（預設）或**對話**。對話檢視把訊息、agent 的思考與工具結果排成像聊天一樣，底部有輸入框，讓你送出下一則訊息。

shell session 只有終端機檢視。

## 切換檢視

在 session 上用 **顯示對話 view** 與 **顯示終端 view** 切換。這個選擇會**一次套用到所有** agent session，重啟後仍然保留，所以新開的 session 會沿用你上次的檢視。同一個選項也在 **設定 → Agent 與 session → Agent session 顯示**。

切換不會重新啟動任何東西。兩種檢視顯示的是同一個執行中的 `claude` 行程；對話檢視在畫面上時，終端機在底下照常執行。

## 內容從哪裡來

對話檢視的內容，取自 Claude Code 替每段對話寫在 `~/.claude/projects` 的紀錄，隨紀錄增長持續讀取。agent 正在工作還是在等待，則來自 Claude Code 執行時回報給 spekterm 的事件。

spekterm 絕不讀取終端機畫面來組成這個檢視。畫面輸出是給人看的，不是給程式讀的；CLI 只要改了繪製方式，讀畫面的做法就會壞掉。對話檢視顯示不了的東西，隨時可以到終端機檢視看。

打開一段很長的對話時，對話檢視只載入最近的一段，並寫明 **更早的訊息尚未載入。** 追上進度期間會顯示 **正在追上進度…**。紀錄完全讀不到時，會顯示 **無法取得對話**，而不是一段空白的對話。

## 送出訊息

在 **傳訊息給 agent** 輸入，再按 **送出**。能不能送出，要看 agent 正在做什麼：

- agent 在等你輸入：可以送出。
- agent 正在工作：檢視會顯示 **處理中…**，agent 不用任何工具、單純在寫回答時也一樣。這時仍然可以送出。Claude Code 會在工作中收下訊息，訊息則出現在對話裡 agent 收下它的位置。
- agent 正在請求使用工具，或在等你選擇：檢視會顯示它在等什麼。請到終端機檢視回答；對話檢視不會把自由文字送進權限詢問或選單。在背景執行的 agent 跳出的詢問也一樣：只要還有詢問沒回答，即使 agent 本身已經結束這一輪，檢視也會一直等它。
- agent 的狀態不明：這發生在 session 剛啟動時，或 Claude Code 沒有回報事件時。檢視寧可拒絕送出，也不去猜。請切到終端機檢視，看看 agent 在做什麼。

你送出的內容以純文字交給 agent，絕不會被當成終端機控制序列解讀。

你送出的 slash command（例如 `/simplify`，或帶參數的 skill）會照你打的那一行顯示。

agent 收到、但不是你打的訊息，會標示來源：**來自** 加上送出它的 session 名稱、**來自 subagent** 加上它的類型、背景通知標示 **背景工作**，其他的（例如 skill 的指示）標示 **脈絡**。另一個 session 傳來的訊息會照那個 session 寫的原樣顯示。agent 工作中收到的其他 session 訊息與背景工作通知也會出現，位置在 agent 收下它的地方。

含有圖片的工具結果會標示張數，例如 **結果 · 1 張圖片**。對話檢視不顯示圖片本身；已配對的手機會顯示（[遠端存取](/zh-tw/docs/using/remote-access/)）。

你送出的訊息在出現於 Claude Code 自己的紀錄之前，會標示 **尚未確認**。如果它一直沒出現，檢視會請你查看終端機檢視，因為那則訊息可能沒有送到。

## 休眠中的 session

休眠中的 session 會顯示 **Session 正在休眠。喚醒後會接回對話。** 按 **喚醒**（或 `Enter`）讓它重新啟動，對話會從停下的地方繼續。見[終端機與 session](/zh-tw/docs/using/terminals-and-sessions/#休眠)。

## 什麼時候用哪一個

- 想讀 agent 做了什麼、跟著讀一段長回答，或在沒有終端機雜訊的情況下送出下一個指示，用**對話檢視**。
- 權限詢問、選單、slash command 選擇器，以及其他任何互動式的操作，用**終端機檢視**；對話檢視告訴你它幫不上忙時也一樣。

## 它需要 Claude Code 提供什麼

spekterm 會替它啟動的每個 `claude` session 加上自己的設定，讓 Claude Code 回報何時開始工作、何時在等待。你自己的 Claude Code 設定、hook 與 status line 照常運作：spekterm 只是附加上去，不會改動你的設定檔。在 spekterm 之外啟動的 agent session 不受影響。

這些設定也讓 Claude Code 能讀取你從手機附加到訊息裡的檔案（見[遠端存取](/zh-tw/docs/using/remote-access/)）。spekterm 把這些檔案放在自己的資料資料夾裡，讀取時不會跳出權限詢問；那裡只允許讀取。關掉 agent 事件回報時，這項權限也不會加上。
