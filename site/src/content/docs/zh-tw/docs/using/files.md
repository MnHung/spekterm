側欄的 **檔案** 身分是一棵檔案樹，列出側欄目前顯示的 repository，並附有檢視器與編輯器，讓你查看與修改打開的檔案。它適合在 agent 旁邊閱讀與小幅修改；更深入的工作請交給 agent 或你自己的編輯器。

在側欄頂端按 **檔案** 即可切換過去。

## 檔案樹

- 目錄在你展開時才載入，所以大型 repository 也能很快打開。
- 每一列會顯示它是檔案還是目錄，以及多久前修改過。標題列則顯示目前看得到幾個項目。
- 磁碟上有檔案建立、修改或刪除時，不論是 agent、build，還是你在別的程式裡動的，檔案樹都會自動更新。
- 指向資料夾之內的 symbolic link，可以像一般目錄一樣展開；指向資料夾之外的則不行：側欄只讀取你加入的資料夾裡的檔案。

repository 若有不只一個 git worktree，檔案樹頂端的 **變更工作目錄** 可以切換要顯示哪一個。每個資料夾各自記得自己的選擇。

## 閱讀檔案

點一個檔案就會打開它。Markdown 會渲染成排版後的樣子，其他檔案則以語法高亮顯示。在 OpenSpec 的檔案上按 **在 OpenSpec 中檢視**，會在 OpenSpec 身分打開同一個 artifact 或 spec；按 **回到檔案樹** 就回來。

repository 裡的 Markdown 一律視為不受信任的內容。原始 HTML 以純文字顯示，script 絕不執行；`http` / `https` 連結會在你的瀏覽器開啟，而不是在 spekterm 裡（其他連結無法點擊）。放在 `https:` 位址上的圖片會載入；見[資料與網路](/zh-tw/docs/reference/data-and-network/)。

## 編輯

打開的檔案可以直接編輯。

- `Ctrl+S` 存檔。
- 有未儲存變更的檔案，會在檔案樹與狀態列上標示。切換檔案或切換資料夾之後，未儲存的變更都還在。
- 如果檔案在你打開之後，磁碟上的內容被改過，存檔時不會直接覆蓋，spekterm 會問你要怎麼處理。
- 有未儲存的變更時關閉 spekterm，會問你要 **全部儲存並結束** 還是 **不儲存並結束**。

編輯器有語法高亮，但不執行語言服務：沒有型別檢查、自動完成或跳到定義。這讓 spekterm 保持輕巧快速；深入的修改請交給 agent 或你的編輯器。

## 新增、重新命名與刪除

在檔案樹上按右鍵，可以選 **新增檔案**、**新增資料夾**、**重新命名** 與 **刪除**。**在根目錄新增** 會建在檔案樹的最上層。

- 建立之前會先檢查名稱。名稱不能用時，會說明原因（名稱為空、保留名稱、某些系統不允許的字元）。
- **刪除** 一定會先問你；項目是目錄或含有未儲存的變更時，也會特別說明。刪除無法復原。
- 資料夾本身不能在這裡改名或刪除；請改從 rail 移除它。

## 快速開檔

焦點在側欄時按 `Ctrl+P`，就能以檔名找檔案。

- 輸入檔名的任何部分，字母只要依序出現即可（`scr` 找得到 `score.ts`）。檔名命中的結果，排在目錄路徑命中的結果前面。
- 搜尋範圍是側欄目前顯示的工作目錄。被 git 忽略的檔案，以及其他 worktree 裡的檔案，不會列出。
- 用方向鍵與 `Enter` 在「檔案」打開檔案；按 `Esc` 關閉清單，焦點會回到側欄。

焦點在終端機時，`Ctrl+P` 會交給終端機，因為 Claude Code 用它來翻 prompt 歷史。請先點一下側欄，或直接用檔案樹。

## 「檔案」碰得到與碰不到的地方

「檔案」只在 rail 上的資料夾之內讀寫。即使透過文件裡的連結，它也打不開這些資料夾之外的路徑。這道邊界只約束側欄：終端機是真正的 shell，你的使用者帳號能去的地方，它都能去。
