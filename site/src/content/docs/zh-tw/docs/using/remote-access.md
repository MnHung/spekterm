遠端存取讓你手機上的 spekterm app **直接**連到電腦上的 spekterm：不需要帳號、沒有中繼站、沒有推播服務。從手機上
你可以看到每一個 folder 與 session、讀取 agent 的對話並回覆、在回覆裡附上照片與檔案、回答 agent 的權限提示與
提問、開新 session、喚醒休眠的 session、替 session 改名、讓它休眠或關閉它、處理收件匣、追蹤你的交接，以及讀取你的 OpenSpec
change。agent 在等你時，手機會收到通知。

在你打開之前，它是**關閉**的。

> **Android app 仍在開發中。** spekterm 這一端已經就緒，app 依據的協定寫在 repo 裡（`docs/remote-protocol.md`）。

## 已配對的手機能做什麼

已配對的手機能做你在 session 裡能做的事：讀取你的 agent 與 shell，並**對它們打字**。agent 有 shell，所以請把
已配對的手機當成你的鍵盤看待。它不能在 session 之外編輯檔案、不能改設定，也看不到你的 Slack 連線或任何憑證。它唯一
能放到你電腦上的檔案是附件，而且只會放進 spekterm 自己的資料資料夾，檔名由 spekterm 決定。

### 背景工作

agent 的這一輪結束之後，可能還留著工作在跑：背景 subagent、背景指令（例如 dev server 或一次測試）、monitor。
手機可以把這些工作列在 session 底下，每一項附上 agent 自己寫的一行說明 —— 於是一個這一輪已經結束、但還有工作在跑的
session，不會看起來像閒著。這份清單是 agent 最後一次回報的內容：agent 的一輪結束、或它的某個 subagent 停下時更新，
session 的程序結束時清空。

### 從手機讓 session 休眠或關閉

手機可以讓 session 休眠（行程結束，session 留在原位，之後再喚醒），也可以關閉它（從你的工作區移除）。兩者都不會
搶走你電腦上的鍵盤焦點，也不會改變你的選取。如果 session 正在忙 —— agent 在工作或在等你選擇、shell 正在跑指令，
或 spekterm 判斷不出來 —— 手機會先被告知原因，問過你之後才照樣結束它。

agent 要求關閉它自己的 session 時，spekterm 不會直接關，而是讓你決定（[交接](/zh-tw/docs/using/handoffs/)）；手機上也會出現同一個
提議，附 **關閉** 與 **保留**。在任一邊回應都算數：在手機上保留，電腦上的提議就會消失；在電腦上保留或對那個 session
打字，手機上的也會消失。agent 這一輪結束時，手機會照常通知你它在等你；提議本身則顯示在那個 session 上。

### 從手機回答提示

agent 請求權限或向你提問時，手機會顯示出來，也能回答：

- **權限提示**：允許一次，或拒絕。「允許」只開放給執行指令、編輯、寫入與讀取檔案、抓取網頁 —— 這些提示的第一個
  選項是「只允許這一次」。「一律允許」類的選項不開放，請在終端裡選。
- **agent 帶選項的提問**：選你要的選項。
- **agent 想執行的計畫**：先讀計畫，再核准（每次修改前詢問，或用 auto mode），或拒絕讓它繼續規劃。

spekterm 會替你按下你會按的鍵，一次一個，絕不把文字或 Enter 送進提示。每按一個鍵之前，它都會確認還是同一個提示、
而且還開著。同時有兩個以上的提示在等，或你已經在電腦上對那個 session 打過字時，手機就不能回答，請回到電腦上答。

### 從手機送出收件匣項目的 prompt

在手機上接受收件匣的項目，會跟在電腦上接受一樣在電腦開好它的 session，第一則 prompt 填好、**不會送出**
（[收件匣與 Slack](/zh-tw/docs/using/inbox-and-slack/)）。支援這項功能的手機 app 會顯示這則等著送出的 prompt
與項目全文，只有在你按下送出時才送 —— spekterm 只是替你按 `Enter`，不做別的。在那之前，手機對那個 session 的
回覆一律被擋下，所以它絕不會跟一則你還沒讀過的 prompt 一起送出去。如果你在電腦上對那個 session 打過字，就在
電腦上完成。

### 從手機回覆

你從手機回覆時，spekterm 會在訊息之外（不是訊息裡面）告訴 agent：這則是你從手機送的，你會在手機上看回覆，
請它回得簡短、適合小螢幕閱讀。你的訊息本身照你寫的原樣送出，之後在電腦上打的訊息也不會帶這段說明。

看著一段對話時，手機也能顯示這個 session 的模型、effort、已用 context、花費與用量上限 —— 也就是電腦上狀態列
顯示的內容（需開啟 **在狀態列顯示 agent 狀態**）—— 以及 agent 能執行的 skill。把 `/名稱` 或 `/名稱 參數` 當成
回覆送出即可執行。清單要等這個 session 收到第一則訊息後才會出現；`/clear` 這類 agent 內建指令不在其中。

### 附加檔案

手機上的回覆可以附上照片、截圖、PDF 與文字檔（每則最多 10 個、每個 10 MB）。spekterm 會把它們放在自己的資料
資料夾，並告訴 agent 檔案在哪裡；agent 讀取時不會跳出許可提示。關閉 session 時會刪除它們，最晚 30 天後也會刪除。

### 替 session 改名

從手機改名的方式和電腦上一樣：名字留空，session 就回到 agent 自己的標題。

從手機開新 session 或喚醒 session，**絕不會把你的桌面搶走**：session 會出現在它的 folder 裡，但你正在看的畫面
與正在打字的位置都不變。

## 打開與配對

1. 打開 **設定**，選 **遠端存取** 分類。
2. 打開 **允許已配對的裝置連線**。spekterm 會開始在畫面上顯示的 port（預設 47615，可以改）上、於每一張網路介面
   等待連線。新的 port 要按 **使用這個 port** 或 **Enter** 才套用，離開欄位不會套用，因為變更它會中斷已連線的裝置。
3. 選 **配對裝置**，用手機上的 spekterm app 掃描 QR code。這組碼只能用一次、五分鐘內有效，而且只在那個畫面開著
   時有效；離開這個分類或關掉設定，它就失效。掃不了的話，畫面上也有同一個連結的文字版。

手機自己保存它的憑證；spekterm 只存它的雜湊。手機會以 QR code 裡的指紋比對 spekterm 的憑證，所以別台電腦冒充
不了你的電腦。

## 網路

手機會連 QR code 裡的位址，哪個通就用哪個：

- **同一個網路** —— 你電腦的區網位址。
- **Tailscale** —— 你電腦的 Tailscale 位址直接就能用；把它的 Tailscale 名稱填進 **額外位址**，就會放進 QR code。
- **port forward** —— 在路由器上轉送那個 port，並把你的公開名稱（例如 DDNS 名稱）填進額外位址。

手機每次連上（不管走哪一條路），spekterm 都會告訴它電腦目前的位址；連線期間位址變了，也會再告訴它一次。
會記住這份清單的手機 app，在電腦的區網位址變了之後不必重新配對：只要它用別的方式連上過一次（Tailscale 或額外位址），下次就有新的區網位址可用。

如果哪一個都連不到你的電腦 —— 人在外面、沒有 Tailscale 也沒有 port forward —— 手機就連不上，也收不到任何通知。

## 通知

agent 在等你、在等你選擇、交接完成，或收件匣有新項目 —— 手機**只會透過它自己對 spekterm 的連線**得知。為了在
背景通知你，app 會一直保持這條連線，這會花一些電。連線斷掉又連回來時，spekterm 會補送手機錯過的事件 —— 最近
24 小時、最多 200 則 —— 或告訴它可能漏了一些。你此刻在電腦上正在看的那個 session，不會發通知。已排程的交接在它開啟時才算到達，不是在排程的時候；在那之前，手機會把它和時間另外列出，也能立即執行或取消它。

## 誰連線中、撤銷與重設

- 有手機連線時，活動列會出現一個手機圖示；點它會打開設定的 **遠端存取** 分類。
- 這個分類列出你已配對的裝置與各自最後連線的時間。**撤銷** 會先確認，再立刻中斷該裝置，之後也一律拒絕它；
  該裝置要重新配對。
- **重設遠端存取** 會產生新的憑證並撤銷所有裝置，每台都要重新配對。若它的私鑰不見了，spekterm 會自己重設，並在
  這個分類裡說明。
- 若遠端存取無法啟動（例如 port 被佔用），這個分類會說明原因，設定的分類清單也會在 **遠端存取** 旁標示。

## 在不信任的網路上

遠端存取會在每一張網路介面上等待連線。在不信任的網路上請關掉它。同一個位址連續失敗太多次會被拒絕一分鐘；和你的
手機共用同一個公開位址的人，可能因此延遲你手機的重新連線。

## spekterm 沒有視窗地執行時（macOS）

在 macOS 上，關掉視窗後 spekterm 仍在執行，遠端存取也照樣等待連線。已配對的手機仍連得上、看得到收件匣，但
session 需要視窗：手機會被告知目前沒有視窗，而 spekterm 不會為它打開視窗。
