遠端存取讓你手機上的 spekterm app **直接**連到電腦上的 spekterm：不需要帳號、沒有中繼站、沒有推播服務。從手機上
你可以看到每一個 folder 與 session、讀取 agent 的對話並回覆、在終端裡回答權限提示、開新 session 或喚醒休眠的
session、處理收件匣、追蹤你的交接，以及讀取你的 OpenSpec change。agent 在等你時，手機會收到通知。

在你打開之前，它是**關閉**的。

> **Android app 仍在開發中。** spekterm 這一端已經就緒，app 依據的協定寫在 repo 裡（`docs/remote-protocol.md`）。

## 已配對的手機能做什麼

已配對的手機能做你在 session 裡能做的事：讀取你的 agent 與 shell，並**對它們打字**。agent 有 shell，所以請把
已配對的手機當成你的鍵盤看待。它不能在 session 之外編輯檔案、不能改設定、看不到你的 Slack 連線或任何憑證，也
不能關閉或讓 session 休眠。

從手機開新 session 或喚醒 session，**絕不會把你的桌面搶走**：session 會出現在它的 folder 裡，但你正在看的畫面
與正在打字的位置都不變。

## 打開與配對

1. 打開 **設定**，在 **遠端存取** 底下打開遠端存取對話框。
2. 打開 **允許已配對的裝置連線**。spekterm 會開始在畫面上顯示的 port（預設 47615，可以改）上、於每一張網路介面
   等待連線。
3. 選 **配對裝置**，用手機上的 spekterm app 掃描 QR code。這組碼只能用一次、五分鐘內有效，而且只在那個畫面開著
   時有效。掃不了的話，畫面上也有同一個連結的文字版。

手機自己保存它的憑證；spekterm 只存它的雜湊。手機會以 QR code 裡的指紋比對 spekterm 的憑證，所以別台電腦冒充
不了你的電腦。

## 網路

手機會連 QR code 裡的位址，哪個通就用哪個：

- **同一個網路** —— 你電腦的區網位址。
- **Tailscale** —— 你電腦的 Tailscale 位址直接就能用；把它的 Tailscale 名稱填進 **額外位址**，就會放進 QR code。
- **port forward** —— 在路由器上轉送那個 port，並把你的公開名稱（例如 DDNS 名稱）填進額外位址。

如果哪一個都連不到你的電腦 —— 人在外面、沒有 Tailscale 也沒有 port forward —— 手機就連不上，也收不到任何通知。

## 通知

agent 在等你、在等你選擇、交接完成，或收件匣有新項目 —— 手機**只會透過它自己對 spekterm 的連線**得知。為了在
背景通知你，app 會一直保持這條連線，這會花一些電。連線斷掉又連回來時，spekterm 會補送手機錯過的事件 —— 最近
24 小時、最多 200 則 —— 或告訴它可能漏了一些。你此刻在電腦上正在看的那個 session，不會發通知。

## 誰連線中、撤銷與重設

- 有手機連線時，活動列會出現一個手機圖示；點它會打開對話框。
- 對話框列出你已配對的裝置與各自最後連線的時間。**撤銷** 會立刻中斷該裝置，之後也一律拒絕它。
- **重設遠端存取** 會產生新的憑證並撤銷所有裝置，每台都要重新配對。若它的私鑰不見了，spekterm 會自己重設，並在
  對話框裡說明。

## 在不信任的網路上

遠端存取會在每一張網路介面上等待連線。在不信任的網路上請關掉它。同一個位址連續失敗太多次會被拒絕一分鐘；和你的
手機共用同一個公開位址的人，可能因此延遲你手機的重新連線。

## spekterm 沒有視窗地執行時（macOS）

在 macOS 上，關掉視窗後 spekterm 仍在執行，遠端存取也照樣等待連線。已配對的手機仍連得上、看得到收件匣，但
session 需要視窗：手機會被告知目前沒有視窗，而 spekterm 不會為它打開視窗。
