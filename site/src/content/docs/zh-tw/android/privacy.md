生效日期：2026-11-06。

spekterm for Android（以下稱「本 app」）是桌面工作台 spekterm 的配套 app，原始碼公開於 [github.com/spekhq/spekterm-android](https://github.com/spekhq/spekterm-android)，可從 [Google Play](https://play.google.com/store/apps/details?id=com.spekterm.android) 下載。

**本 app 不會把任何資料傳給開發者。** 本 app 沒有帳號、沒有自己的伺服器，不含分析、廣告、當機回報或推播服務。

## 連線

本 app 會連到你配對的那台執行 spekterm 的電腦；配對進行中，則只連到你選的配對連結或 QR code 裡的位址。它直接連線——經由你的區域網路、Tailscale 或你自行轉發的連接埠——而這一直是它的首選。連線以 TLS 加密，本 app 只接受你配對的那台桌機的憑證（憑證指紋來自配對碼），因此中間的任何人都讀不到連線內容，包括本 app 的開發者。

**經團隊的伺服器。** 只有在你的桌機加入了團隊、而且你打開了「經團隊伺服器連到這台電腦」的設定時，桌機才會給本 app 一張該伺服器的通行證；直接的位址都連不上時，本 app 也可以經它連到桌機。那台伺服器是你的團隊自己架設的 spekterm-server，也就是你的桌機所加入的那台——不是本 app 的開發者架設的。到桌機的連線仍然是端對端加密：在裡面，本 app 一樣只接受你桌機的憑證，所以團隊的伺服器讀不到、也改不了經過的內容。團隊的伺服器看得到的是你手機的 IP 位址、什麼時候連線、連了多久、雙向各傳了多少位元組，以及用的是哪一張通行證；它的紀錄只記 id、時間長度與位元組數，不記位址或內容。配對一律直連。

## 送到你桌機的東西

你輸入的回覆、你對 agent 的提問或權限請求所做的回答，以及你附加的照片、PDF 和文字檔，只會送到那台桌機。這些內容到了桌機之後怎麼處理，由你的 spekterm 和你在上面執行的 agent 工具決定：AI coding agent 可能會把它們送到它的 AI 服務供應商，並適用該供應商的條款。送出前，本 app 會把附件複製到自己的快取（HEIC 照片會轉成 JPEG），這份複本會在本 app 的行程結束時刪除。桌機會把你的 session、對話、收件匣項目和 OpenSpec 檔案傳給本 app 顯示；這些內容只在顯示時保留在記憶體中，本 app 不會儲存。

## 相機

相機只用來掃描桌機的配對 QR code。畫面在手機上解碼，不會儲存，也不會傳出去。

## 留在手機上的東西

配對資料（桌機的位址、憑證指紋，以及受手機 Android Keystore 保護的憑證）、桌機給的團隊伺服器通行證（若有，以同樣方式保護）、少數偏好設定，以及供疑難排解用的連線紀錄，都留在手機上，並排除在 Android 備份與裝置轉移之外。連線紀錄記錄的是連線事件、桌機的位址和各項請求的結果，不含訊息內容、名稱或標題；只有你自己從設定分享出去時，連線紀錄才會離開手機。取消配對會刪除憑證；解除安裝本 app 會刪除它儲存的所有資料。

## 連結

本 app 顯示的內容中若有連結，只有在你點了之後，才會用瀏覽器或其他 app 開啟。本 app 本身不會從網路載入圖片或其他內容。

## 權限

| 權限 | 用途 |
|---|---|
| 網路、網路狀態 | 連到你的桌機，並在網路變化時重試 |
| 前景服務（特殊用途） | 讓連到桌機的連線保持開著，桌機的通知才收得到；可以從它的通知暫停 |
| 通知 | 在 agent 需要你、交接完成或收件匣有新項目時通知你 |
| 相機 | 掃描配對 QR code |
| 開機後執行 | 手機重新開機後重新連線 |
| `DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION` | 由 AndroidX 函式庫加入，讓本 app 內部的廣播只在本 app 內傳遞 |
