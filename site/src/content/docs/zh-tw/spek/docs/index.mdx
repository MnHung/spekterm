spek 是唯讀的 [OpenSpec](https://github.com/Fission-AI/OpenSpec) 內容檢視器，有四種形式：VS Code 擴充套件、JetBrains 外掛、從原始碼啟動的網頁版，以及產出靜態頁面的 GitHub Action。四種都呈現同樣的畫面，也都不會修改任何檔案。
