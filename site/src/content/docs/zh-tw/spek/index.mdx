## spec 是寫來讀的

OpenSpec 把專案的 requirement 和每一次修改，都存成 `openspec/` 底下的 Markdown 檔。這種格式方便 agent 撰寫、方便 git 追蹤，讀起來卻很吃力：一個 change 包含 proposal、design、task 清單，再加上每個 capability 各一份 delta，散落在十幾個檔案裡。spek 讀取這個目錄，替你排出結構、串起 spec 與 change 之間的連結，進度一眼就看得到。

## spek 與 spekterm

spek 的引擎也替 [spekterm](/zh-tw/) 讀取 OpenSpec。spekterm 的側欄以 spek 的核心套件（`@spekjs/core`）掃描 spec 與 change，並繪製 spek 的關係圖與時間軸（`@spekjs/ui`）。spek 讓你在平常工作的地方讀 spec；spekterm 則是在 spec 旁邊跑 Claude Code session 的桌面工作台。兩者互不依賴。
