## 不再是四個終端機分頁加一個編輯器

同時在幾個 repository 裡跑 agent，通常就得開一疊終端機分頁，外加一個只為了看規格才切過去的編輯器。spekterm 把每個 repository 的 session 收進同一個視窗，規格也一直留在眼前。它的側欄懂 OpenSpec：會顯示 agent 正在做的 change，並隨著 agent 寫入磁碟即時更新。

## 不會隨手消失的 session

<Screenshot
  wide
  src={terminal}
  alt="shell session 顯示 git log 與 change 的檔案，旁邊的側欄顯示這個 change 的 proposal。"
  caption="真正的終端機，每個 repository 可以開好幾個，旁邊就是 change 的 proposal。"
/>

- **真正的終端機** —— `claude` 與你的 login shell 跑在真正的 pty 裡。每個 repository 可以開好幾個，也能開在 git worktree 裡。
- **重開 app 也還在** —— `claude` session 會接續原本的對話；shell 會重播先前的畫面，並回到上次的目錄（macOS 上則回到它的資料夾）。
- **用不到的就讓它休眠** —— 可以手動休眠，閒置一天後也會自動休眠。休眠的 session 會結束行程，直到你喚醒它。

## 讀 agent 在做什麼，不只是看終端機

把 agent session 切到對話檢視，就能以訊息與工具呼叫的形式閱讀整段往來。內容來自 agent 自己的紀錄與 hooks，spekterm 從不解析終端機畫面。要回到終端機，點一下就行。

## 怎麼運作

<Steps>

1. **把你的 repository 加進工作區。**
2. **在其中一個 repository 開 Claude Code session** —— 或開 shell，或兩個都開。
3. agent 工作時，**在側欄跟著 change 走**，隨時都能介入。

</Steps>

## 本機優先、開放原始碼

spekterm 是桌面 app：你的 repository、session 與設定都留在你的電腦上。它沒有帳號、沒有遙測；它會向 GitHub 查詢新版本，而這可以關掉。它替你啟動的程式，也就是 `claude` 與 `openspec` 這兩個 CLI，會自己連網；[資料與網路](/zh-tw/docs/reference/data-and-network/)逐項列出什麼連到哪裡。spekterm 以 MIT 授權釋出，原始碼在 [GitHub](https://github.com/spekhq/spekterm)。

## 以 spek 為基礎

<SpekLogo />

[spek](/zh-tw/spek/) 是 spekterm 的姊妹專案，出自同一群維護者：一個開源、唯讀的 OpenSpec 內容檢視器。它可以在瀏覽器、VS Code、JetBrains IDE 裡使用，也能由 CI 產出靜態頁面。spekterm 的側欄建立在 spek 的成果上：

- **讀懂 OpenSpec 的引擎** —— 掃描 spec 與 change、計算 task 進度、聚合 worktree，都來自 spek 的核心套件 `@spekjs/core`。
- **關係圖與時間軸** —— 與 spek 用的是同一套元件，來自它的 `@spekjs/ui` 套件。
- **圖示** —— spekterm 的圖示就是 spek 的 S，旁邊加上一個終端機提示字元。

側欄本身是 spekterm 自己做的，專為終端機旁的窄欄設計。想在平常工作的地方讀 spec，就用 spek；要同時指揮多個 repository 的 agent，又想讓 spec 留在手邊，就用 spekterm。兩者讀的是同一批檔案，各自都能單獨使用。
