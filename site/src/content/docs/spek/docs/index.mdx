spek is a read-only viewer for [OpenSpec](https://github.com/Fission-AI/OpenSpec) content. It comes as a VS
Code extension, a JetBrains plugin, a web app you start from its source, and a GitHub Action that builds a
static page. All four show the same views, and none of them changes a file.
